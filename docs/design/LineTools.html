Line tools

A mockup for Ryan to try before it gets built. One click picks a line, it doesn't edit it. Double-click (or Enter) edits. Marker and Note are tools you pick up: your pointer turns into a flag or a pencil, lines glow yellow or red under it, and clicking a line puts it there. The window below works, try it.

Try this

  1. Move the mouse over the lines: a soft grey shows which one you're on.
  2. Click a line once: it's picked (blue), nothing opens. Three small buttons show on its right: flag, note, and + (add a line under it).
  3. Double-click a line (or pick it and press Enter): now you edit it. Enter saves, Esc cancels, clicking anywhere else only saves.
  4. Click Marker in the top bar: your pointer is a flag, lines glow yellow. Click a few lines to mark them, click a marked line to take the flag off. Esc or Marker again puts the tool down.
  5. Click Note: the pointer is a pencil, lines glow red. Click a line and type the note. The tool goes down by itself after one note.
  6. Pick a line and click +: an empty line opens under it to type in.
  7. Press ⌘Z (or Undo at the bottom) after any change: it comes back.
  8. With a line picked: ↑ ↓ move, Delete deletes it (with Undo).

What I picked, tell me if you want it different

  • Marker stays on until you put it down, so you can flag several lines in a row. Note goes down after one note, because you type it right away.
  • ⌘D still marks "right now" while recording (the line being said), so in class you don't have to find the line. The Marker button is the tool for any other line.
  • Red for notes, yellow for markers, like you said. The color is only while the tool is in your hand. Marked lines keep the flag by the time, notes stay in the brown pencil color under the line.
  • + works on every line, also after Stop (right now Add line below only shows up while it's still live text).
  • Right-click still works for everything, nothing is taken away.
